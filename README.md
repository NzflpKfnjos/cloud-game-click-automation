# 云游戏点击脚本助手

这是一个 Tampermonkey 用户脚本，用于在腾讯云游戏网页画布上记录和重放点击位置。

## 安装

1. 打开 Tampermonkey 的脚本管理页。
2. 新建用户脚本，将 `cloud-game-click-automation.user.js` 的内容粘贴进去。
3. 保存后刷新云游戏页面。

首次运行会自动载入脚本内置的 5 个坐标。脚本会把坐标按画布比例保存，画布尺寸变化后仍可复用。

## 使用

- `记录`：点击游戏画面添加坐标，再点击一次结束记录。
- `运行`：按顺序执行坐标点击。
- `停止`：中止当前运行。
- `间隔(ms)`：相邻坐标之间的等待时间。
- `循环(0=无限)`：执行轮数，0 表示持续运行。
- `清空坐标`、`导出`、`导入`：管理坐标配置。
- 快捷键：F8 运行/停止，F9 开始/结束记录，Esc 停止。

## 画面卡住监控

从 1.4.0 开始，用户脚本会向外层页面发送 5 秒一次的诊断心跳，并监控 WebRTC 入站视频流、视频帧进度、页面长任务和脚本错误。

- 连续 25 秒收不到内嵌页心跳时，外层页面会判断页面无响应并自动重连。
- 连续 45 秒没有收到新的视频数据或解码帧时，会判断画面停止更新并自动重连。
- 内嵌 WebRTC 进入 `failed` 时会提前触发重连，不等待 45 秒停帧阈值。
- 断线重建后的 iframe 会在 30 秒内确认心跳和媒体帧；首次加载使用 60 秒启动窗口。
- 页面切到后台时暂停卡顿判定，避免浏览器后台节流造成误判。
- 15 分钟内最多自动恢复 3 次，防止异常情况下无限刷新。
- 页面不会按固定间隔刷新，避免主动销毁 WebRTC 会话和丢失内嵌页面状态。
- 用户脚本不提供应用切换下拉，会根据当前网页 URL/hash 中的游戏 ID 自动选择配置。
- 同一款游戏因断线重建 iframe 后，会恢复之前正在运行的点击任务；手动停止或切换游戏会清除恢复意图。
- 顶部提供 `重新连接`、`诊断日志`、`导出日志` 按钮。问题再次出现时，可导出 JSON 日志用于排查。

> 需要同时更新 `index.html` 和 Tampermonkey 用户脚本到 1.5.0。若日志提示“未收到内嵌页监控心跳”，请确认 Tampermonkey 允许脚本在 iframe 中运行。
