# 云游戏点击脚本助手

这是一个 Tampermonkey 用户脚本，用于在腾讯云游戏网页画布上记录和重放点击位置。

## 安装

1. 打开 Tampermonkey 的脚本管理页。
2. 新建用户脚本，将 `cloud-game-click-automation.user.js` 的内容粘贴进去。
3. 保存后刷新云游戏页面。

每次加载会按当前游戏载入默认配置：金铲铲 5 个坐标、间隔 100 毫秒；火影忍者 11 个坐标、间隔 50 毫秒。脚本会把坐标按画布比例保存，画布尺寸变化后仍可复用。

## 使用

- `记录`：点击游戏画面添加坐标，再点击一次结束记录。
- `运行`：按顺序执行坐标点击。
- `停止`：中止当前运行。
- `间隔(ms)`：相邻坐标之间的等待时间。
- `循环(0=无限)`：执行轮数，0 表示持续运行。
- `清空坐标`、`导出`、`导入`：管理坐标配置。
- 快捷键：F8 运行/停止，F9 开始/结束记录，Esc 停止。

## 重新连接

- 页面首次打开或切换游戏时加载当前游戏的 iframe。
- 点击 `重新连接` 会立即重新加载当前游戏的 iframe。
- 页面不会按固定时间自动刷新；重新连接不依赖心跳、网络状态或画面检测。
- 用户脚本不提供应用切换下拉，会根据当前网页 URL/hash 中的游戏 ID 自动选择配置。
- 同一款游戏重新加载后，用户脚本会在画布出现时恢复之前正在运行的点击任务；手动停止或切换游戏会清除恢复意图。

> 请同时更新 `index.html` 和 Tampermonkey 用户脚本（1.6.1），并允许脚本在 iframe 中运行。

## 验证

运行 `node --test tests/reconnect.test.cjs` 检查初始加载、手动重连和游戏切换行为。测试无需额外依赖。

## 卡顿诊断日志

页面和用户脚本会把诊断记录写入同一个 `localStorage` 键 `cloud-game-click-diagnostics-v1`，最多保留最近 3000 条。记录包含页面/脚本会话、iframe 加载与错误、网络和可见性变化、跨 iframe WebRTC/心跳消息、未捕获异常、长任务、事件循环延迟、内存快照、点击运行步骤和恢复意图；刷新页面不会清除这些记录。

出现画面卡住时先不要刷新，点击页面顶部的“导出诊断日志”（或脚本面板的“导出日志”），保存下载的 JSON 后再刷新。若页面完全无法点击，可在开发者工具 Console 执行：

```js
copy(localStorage.getItem('cloud-game-click-diagnostics-v1'))
```

日志中的 `watchdog.delayMs` 明显增大、`long-task`、`window-error`、`unhandled-rejection`、`iframe-message` 和 `network-*` 事件可用于区分主线程阻塞、脚本异常、WebRTC 状态变化和网络问题。

日志默认关闭，点击“开始记录日志”（用户脚本中为“开始日志”）后显示绿色“● 日志记录中”；再次点击停止。刷新后保留日志与记录开关。外层页面与云游戏 iframe 属于不同来源，日志分别存储，页面通过消息汇总 iframe 诊断；需要同时更新页面与 Tampermonkey 脚本到 1.6.1。
